# Screen recording guide

Keep the walkthrough between three and five minutes.

1. Introduce the engineering-manager problem in one sentence.
2. Show dashboard totals and the developer directory.
3. Open a developer profile and explain the connected data.
4. Show why each recommended reviewer was selected.
5. Use the team builder with two or three skills.
6. Search and filter the interactive graph, then inspect a node.
7. Briefly show the graph model and parameterized Cypher in the README.
8. End on the deployed application URL.

Do not display `.env`, the CognoDB console password, or terminal output containing
credentials during the recording.
